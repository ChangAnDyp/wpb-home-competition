## 一、先明确：单人陪练能测什么、不能测什么

这一条很重要，直接决定哪些结论可信。

| 能力 | 1 人能否验证 | 说明 |
|---|---|---|
| 能否注册成功 | 能 | 自己说名字、采集人脸 |
| 能否认出"是主人" | 能 | 自己站到镜头前 |
| 能否播报正确名字 | 能 | |
| 动作识别（坐/躺/摔倒/挥手） | 能 | 自己做动作 |
| 机械臂 / 开关语音交互 | 能 | |
| 导航、建图、航点 | 能 | 不依赖人数 |
| **能否区分 2 个不同的人** | **不能** | 需要第二个人 |
| **能否拒绝非主人（客人）** | **不能** | 需要第二个人 |
| **多人"领先幅度"阈值标定** | **不能** | 需要至少 2 人做对照 |

### 变通办法（建议采用）

第 2 个"人"可以用**照片**代替，用来验证多主人代码逻辑，虽然不如真人有说服力：

1. 找一张别人的清晰正面照（同学、网图都行），打印出来或用另一部手机显示
2. 把它当作"第二位主人"注册进档案（注册工具支持只有照片的注册）
3. 测试时：自己站前面应报你的名字；举着那张照片应报第二个名字；
   举一张从未注册过的照片应判为"不认识"

这样能验证**代码路径通不通**，但**阈值是否可靠仍需真人**。心里要有数：
这条只能证明"逻辑对"，不能证明"比赛现场不会认错人"。

## 五、今天（9/28）就要做的三件事

### 1. 启动动作识别服务

```bash
bash ~/competition/start_ollama.sh
```

### 2. 注册你自己为主人（终端 1）

```bash
cd ~/catkin_ws
source /opt/ros/noetic/setup.bash
source devel/setup.bash
roslaunch wpb_task1_owner_search owner_voice_reid_test.launch \
  owner_count:=1 navigate_enabled:=false start_navigation:=false
```

三个参数的作用（都不能省）：

| 参数 | 为什么必须传 |
|---|---|
| `owner_count:=1` | 节点内部默认注册 **3 位**主人；你只有 1 个人，不传会卡在第二、第三位 |
| `navigate_enabled:=false` | 否则注册完会自动导航去 `living_room`，而你现在还没有航点，会失败 |
| `start_navigation:=false` | 只关掉导航栈（底盘/雷达/move_base/RViz），相机和语音仍会启动，跑得更快 |

然后按语音提示操作：

1. 机器人说"请说姓名" → 你**清楚地报出名字**
2. 机器人复述并请你确认 → 回答"确认"
3. 机器人提示"请慢慢转向侧面" → **缓慢转身**让它采到正面和侧面特征
4. 结束后它进入识别循环，你站到镜头前应当听到"我已经识别到主人\<你的名字\>"

### 3. 检查注册结果

```bash
ls -la ~/catkin_ws/src/wpb_task1_owner_search/data/reid_owner_voice/
```

应该看到 `owner_profile.npz` 和 `owner_profile.json`。用下面这段确认

```bash
python3 - <<'PY'

for f in sorted(glob.glob(base + "*.npz")):
```

**必须看到 `has_face = True`**，否则说明注册时 InsightFace 没生效，等于白注册。

### 补充说明：两个注册工具的区别（别用错）

| 工具 | 会采集名字吗 | 结果存到 | 用途 |
|---|---|---|---|
| `owner_voice_reid_test.launch` | **会**（语音报名字 + 确认） | `data/reid_owner_voice/` | **测试"播报主人名字"必须用这个** |
| `person_reid_owner_test.launch` | **不会**，只说"识别到主人" | `data/reid_owner/` | 只验证人体 ReID 能不能认出同一个人 |

因为规则评分标准是"**以语音播报主人名字为主要依据**"，
所以验证 150 分那条链路必须用前者。
